PROJECT ILHAM (LOMA WEB DESIGN)

1. Klik kanan ZIP > Extract All / Ekstrak Semua.
2. Pasang Node.js versi 24 dari https://nodejs.org/ jika belum ada.
3. Buka folder project-ilham di VS Code melalui File > Open Folder.
4. Terminal > New Terminal. Ketik: npm start
   Bisa juga ketik: node --env-file-if-exists=.env server/index.mjs
   Pada Windows, file MULAI-WINDOWS.cmd menjalankan perintah yang sama.
5. Buka http://localhost:3000 di Chrome. Biarkan terminal tetap menyala.

Tidak perlu npm install. Tidak perlu Live Server.
Untuk login sungguhan, jalankan server tersebut; klik dua kali index.html hanya
membuka tampilan statis. Daftar email membuat akun baru dan menyimpan data ke server.

Google, Facebook, dan SMS: isi kredensial pengelola sesuai docs/LOGIN.md.
Jangan kirim rahasia akun kepada orang lain atau memasukkannya dalam file frontend.

Website memakai satu dokumen utama; menu berpindah ke bagian dalam dokumen.
Login/pengaturan akun terbuka hanya dari Masuk/Akun. Informasi kontak paling akhir.

PENTING TENTANG DESAIN: ZIP sumber terbaru hanya berisi modul Foto Produk.
Beranda lain yang memakai foto latar penuh tidak terdapat dalam arsip itu.
Baca README.md sebelum menilai kesesuaian halaman pertama.

PENTING UNTUK LOMBA: guide book meminta web statis. Gunakan folder lomba-statis
untuk versi tanpa server. Versi itu tidak memiliki login/penyimpanan akun sungguhan.
Baca docs/PANDUAN-LOMBA.md untuk batas dan hal yang belum terverifikasi.
