# Catatan penyesuaian dengan guide book

Acuan: guide book Web Design Siswa 2026 yang diberikan, terutama bagian C.1 pada halaman PDF 7–8 serta penilaian pada halaman 14. Keterangan di sini bukan persetujuan panitia.

| Ketentuan yang dibaca | Implementasi dan batas |
| --- | --- |
| Minimal 1, maksimal 7 halaman | Satu index.html; semua bagian tersambung. Dialog akun bukan dokumen kedua. |
| Website statis | Folder `lomba-statis` adalah versi statis. Versi root dengan server akun tidak memenuhi persyaratan ini bila diajukan sebagai website statis. |
| Bahasa Indonesia | Konten dan pesan interaksi utama berbahasa Indonesia. |
| Framework/library JavaScript selain jQuery dilarang | Frontend memakai JavaScript native dan CSS kustom, tanpa framework/runtime eksternal. |
| Framework/library yang digunakan wajib CDN | Tidak memakai framework/library frontend. Aset font dan gambar lokal, JavaScript proyek ditulis dalam file sendiri. |
| Media pihak ketiga memerlukan Open License dan sumber | Lisensi font/ikon disertakan, sumber foto dicatat. Status Open License foto yang disediakan dalam ekspor belum terbukti; ini masih perlu diselesaikan oleh pemilik sebelum pengumpulan. |
| Orisinalitas, tanpa template website siap pakai | Basis visual adalah desain yang diberikan pemilik. Tidak ada surat pernyataan atau klaim seluruh karya dibuat tanpa bantuan. Penggunaan bantuan harus mengikuti aturan dan penjelasan yang benar kepada panitia. |
| Survei/uji coba harus dari responden nyata | Tidak membuat statistik responden, testimoni nyata, atau bukti uji pengguna fiktif. |
| Responsif, aksesibilitas dan navigasi | Anchor nyata, keyboard native, dialog, label formulir, range, reduced motion, dan media query. Verifikasi visual pada perangkat nyata masih diperlukan. |

Subtema yang dipakai: **Empowering Digital Business for a Smarter Economy**. Fungsi belajar fotografi produk dan menyusun katalog mendukung literasi digital usaha lokal.

Folder statis mempertahankan materi, pencarian lokal, slider, kuis lokal, FAQ, serta ekspor katalog. Tombol Masuk membuka penjelasan versi statis; tidak berpura-pura mengautentikasi pengguna. Progres pengunjung hanya pada perangkatnya. Untuk login nyata gunakan versi aplikasi, dan jangan menyatakan backend itu sebagai bagian statis yang otomatis sesuai guide book.

Proposal, mockup ukuran lomba, data survei nyata, dokumen orisinalitas, dan hosting publik belum dibuat dalam tugas perbaikan ini. Website tidak menampilkan badge acara atau watermark generator. Kredit/lisensi pihak ketiga tetap dipertahankan.

Acuan halaman pertama berfoto latar penuh belum tersedia. Jangan menyatakan desain itu sudah dipulihkan persis sebelum sumbernya diberikan dan dibandingkan.
